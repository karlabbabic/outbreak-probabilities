Poisson processes, renewal models, and outbreak probability

This page gives a short overview of the ideas behind the calculator: the Poisson distribution, Poisson processes, renewal models, and the analytic outbreak probability calculation built from early case counts.

Poisson distribution

The Poisson distribution is a discrete probability distribution for counting how many times an event occurs in a fixed interval of time or space.

Here, λ is the mean rate. For a Poisson random variable, the mean and variance are both equal to λ.

Poisson distribution is used in transmission models as they are random and discrete variables over often independant time periods.

Connection to the binomial distribution

The Poisson distribution can be derived from the binomial model by taking a large number of trials with a small success probability. If the number of trials is n, the success probability is p, and the mean is fixed as λ = np, then taking n → ∞ and p → 0 gives the Poisson form.

After substitution with p = λ/n and simplification, the limiting expression becomes the Poisson PMF above.

Poisson process and renewal model

A Poisson process measures the random time required for a fixed number of events to occur. The waiting times between events are exponentially distributed, which makes the Poisson process a special case of a renewal process.

In an epidemic setting, a renewal model links the number of reportedcases at time t to earlier cases and a serial-interval weight distribution w.


How the serial interval enters the model

Each earlier case contributes to future cases through a delay distribution. If a parent case is observed at week t, then offspring cases can appear at later weeks with probabilities w1, w2, w3, ....

The first few observed weeks are informative as they constrain the likely range of R and therefore the probability of a larger outbreak. The initial model weights are built on a continuous gamma disribution with a set serial interval and standard deviation from a previous outbreak. The maximum weeks is capped at Kmax=50 to remove the tail of the distribution and normalised for the equation.

The serial interval is a key component of the renewal model, as it captures the time delay between successive cases in a transmission chain. The basis of the model removes negligible contributions and normalises for a more accurate estimation of the reproduction number and outbreak probability.

Key ideas

Poisson distribution:

Denotes the amount of times an event occurs in a set interval of time

Waiting times:

In a Poisson process, the waiting time between events is exponentially distributed.

Serial interval:

Previous events contribute to future event occurences through a delay distribution

Renewal processes:

A renewal process generalizes the Poisson process by allowing more general waiting-time distributions.

Analytical model

  1. Accepts early weekly case counts.
  2. Evaluates a grid of possible R values.
  3. Computes the posterior over R.
  4. Combines that posterior with extinction probability.
  5. Returns the probability of a major outbreak.

Limitations

Analytical model

  • The analytical model is only valid for the first 5 weeks of data.
  • It assumes that the reproduction number is constant over time.
  • It does not account for other changes in transmission over time.

Trajectory model

The trajectory model only includes those simulations which match the first 3 weeks of inputs but might not be

Machine learning model

  • The ML scripts are only available for weeks 1–5.
  • If >5 weeks are required, a new script must be created.
  • The ML scripts expect features to be named sequentially, such as week_1, week_2, ..., week_N.
  • The script relies on input (simulated) data.
