Approaches summary

This pages provides information on three approaches for estimating outbreak probability from early case data. The third approach is a machine learning method that uses a trained model to learn the relationship between early case patterns and the probability of a major outbreak.

Analytics solutions

This approach uses a discrete-time renewal process to compute the outbreak probability.

Input

  • The first k days of simulated infection data from simulated_cases.csv
  • An estimated range for the reproduction number

Output

  • Conditional probability P([I1, I2, I3] | R)
  • Outbreak probability given first three cases P(PMO | [I1, I2, I3])
  • Outbreak probability given reproduction number P(PMO | R)
  • Overall outbreak probability
Overall outbreak probability = conditional probability × outbreak probability given reproduction number

What to do

  • Numerically compute the integral for the serial interval distribution
  • Compute the expected number of new cases

Trajectory matching

    The trajectory matching approach

    compares observed early case counts to simulated epidemic trajectories. This method compares observed early case counts to simulated epidemic trajectories and keeps only the trajectories that match the beginning of the data.

Input

  • Sequence of case counts

Output

  • All trajectories where the first k days of simulated data match the observed sequence
  • Outbreak probability as the fraction of those trajectories classified as major outbreaks

Machine Learning

This approach uses a trained model to learn the relationship between early case patterns and the probability of a major outbreak. here the first three weeksof incidence [I1 I2 I3] are taken as predictors and the outcome (major or minor outbreak) as the response. We train random forest classifiers, with the trainingset size ranging from 1 up to 1,000,000 observations.

Input

  • An observed early sequence of case counts, for example data = [1, 2, 6]
  • Machine learning model(s) trained on simulated trajectories

Output

  • Predicted outbreak probability
  • Model metrics
