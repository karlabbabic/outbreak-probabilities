Method

Trajectory matching


The trajectory model is based on a large number of simulated outbreaks and requires the use of the renewal equation models. Values of R0 and I1 used are sampled from their priors. In our analyses with complete reporting, we assume that the value of I1 is known so that the prior is a point mass, but when we consider under-reporting we use a Poisson distributed prior for I1.


Key idea: The trajectory matching method involves identifying simulated outbreaks (from the training dataset) with early disease incidence matching the dataset and calculating the proportion of matching simulations in which a major outbreak went on to occur

Given an observed input sequence of early case counts (e.g. [1, 2, 0] for the first three weeks), we retain only those simulations whose incidence in the first three weeks exactly matches the input.

Workflow

The trajectory model can be broken down into the following steps

  1. Sample a value of R0 from its prior distribution.
  2. Sample a value of I1 from its prior distribution.
  3. Simulate an outbreak using the renewal equation model.
  4. Repeat steps 1–3 a large number of times to generate simulated outbreaks.
  5. For each simulated outbreak, calculate the probability of a major outbreak given the number of infections in the first few weeks.
  6. Average the probabilities across all simulated outbreaks to obtain an overall estimate of the probability of a major outbreak.
